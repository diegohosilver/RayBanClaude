Help

  • App won't connect? Are phone and PC on the same Wi-Fi? On Windows, answer the firewall prompt on first start with “Allow” (private network).
  • “Unauthorized”? Scan the QR code again – the token has to match.
  • No answer from Claude? Claude Code has to be running with the command above; check /mcp in Claude.
  • Glasses not streaming? Meta AI app → glasses → turn on developer mode, unfold the temples, restart the glasses.
  • Port in use? End the other Claude session running RayBan Claude or set RAYBANCLAUDE_PORT.
